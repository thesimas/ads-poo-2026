## Acerte o número

> Faça um programa que gere um número aleatório entre 1 e 100 e peça para o
usuário acertar o número. 
>> Se o usuário acertar, o programa deve imprimir “Parabéns, você acertou!ˮ
e indicar quantas tentativas foram necessárias para acertar o número. 
>>> Caso contrário, o programa
deve avisar se o número informado é maior ou menor que o número sorteado e pedir para o usuário
tentar novamente. 
>>>> O programa deve continuar pedindo para o usuário tentar acertar o número até
que ele acerte.
